## Репозиторий

`wisoqu/Light-Horror-browser-game`, браузерный хоррор от первого лица на
Three.js r160 (лежит в `lib/`, без CDN). «Дежурная не ушла»: ночная гимназия
№ 42, четыре щитка, дежурная, которая слышит бег и видит фонарь.

Работай **в своей ветке**, не в ветке `arena/e44e6e75-light-horror-browser-game`
— она моя, и я в ней прямо сейчас меняю файлы.

Что уже есть в ветке `main`:

- `src/map42.js` — план школы 38×16 клеток по 2,2 м: 14 помещений, двери, арки,
  точки интереса. `docs/school-plan.svg` — подписанный план.
- `src/textures.js` — процедурные материалы (Canvas 2D), ни одного файла.
- `src/props.js` — батчер `Kit` и ~30 сборщиков мебели.
- `src/world.js` — сборка сцены: коллайдеры, 71 лампа, 26 окон, якоря,
  поиск пути (`isWallWorld`, `hasLineOfSight`, `nextStepWorld`, `bfsDistance`,
  `randomOpenNear`).
- `src/monster.js` — модель дежурной (2,01 м) и риг скримера.
- `src/scares.js` — режиссёр страшилок, 8 событий с кулдаунами.
- `src/jumpscare.js` — скример в камере, 1,05 с.
- `src/main.js` — **игровая логика, не твоя и не моя**. Читать можно, править
  нельзя.
- `index.html`, `style.css` — интерфейс.
- `docs/DESIGN.md` — что и зачем сделано, `docs/PARALLEL.md` — правила работы
  в параллель (прочитай его первым).

## Твоя часть

Ты — **звук, QA и инфраструктура**. Твои файлы (и только они):

Три задачи, по убыванию важности.

### 1. Звук — главное

Сейчас `src/audio.js` — процедурный синтез (осцилляторы, шум, фильтры) с
набором одноразовых событий. Он работает, но плоский: нет чувства помещения,
шаги одинаковые на линолеуме и в спортзале, приближение дежурной слышно
только по громкости.

Нужно:

- **слои помещения**: глухой деревянный кабинет, гулкая рекреация с
  реверберацией, звонкий спортзал, тесная электрощитовая. Определять комнату
  по `world.rooms` / `roomAtCell` из `src/world.js` — читать можно, менять нет.
- **шаги по поверхностям**: линолеум, паркет, плитка, бетон, маты зала.
- **дежурная**: направленный гул, который становится ближе; дыхание, когда
  она рядом; отдельный слой на погоню (`hunted`).
- **стингеры под каждое событие** `scares.js`: `apparition`, `window`,
  `lights`, `chalk`, `locker`, `whisper`, `behind`, `slam`. Сейчас половина
  из них переиспользует общие `thud`/`flicker` — сделай каждому свой голос.
- **микс**: общий выход не выше −3 дБFS, пики 0,3–0,4 как сейчас; при
  `document.hidden` — тишина.

Жёсткие ограничения:

- **никаких аудиофайлов и CDN** — только WebAudio-синтез, проект работает
  офлайн;
- публичный контракт `GameAudio` сохранить: `init`, `resume`, `setMaster`,
  `update(dt, {panic, enemyDist, enemyLos, hunted})`, `step`, `breath`, `gasp`,
  `heartbeat`, `whisper`, `stinger`, `thud`, `fuseFix`, `spark`, `pickup`,
  `paper`, `locker`, `flicker`, `doorRattle`, `scream`, `winChime`, `tone`,
  `noise`. Сигнатуры и смысл — те же, внутренности — твои.
- `update()` вызывается каждый кадр: не создавай узлы, если параметр не
  изменился.

### 2. QA

- Перенеси валидатор мира в репозиторий: `tools/validate-world.mjs` — проверяет,
  что все проходимые клетки достижимы и для игрока, и для дежурной, что старт
  свободен, что ни один якорь (щитки, шкафчики, записки, батарейки, окна,
  доски) не замурован в стену.
- `node:test`-проверки на контракты: план (`tests/map42.test.mjs` уже есть,
  11 проверок), материалы, реквизит, режиссёр страшилок (что `trigger` каждого
  вида не бросает исключение и не оставляет висящих мешей).
- Ничего не запускай через `node --test tests/` — каталог ломает загрузку
  модулей, только `node --test tests/map42.test.mjs`.

### 3. Инфраструктура

- ESLint + Prettier **без массового переформатирования** существующих файлов:
  правила только для новых, старые — `// eslint-disable` не ставить, лучше
  мягкий конфиг.
- GitHub Actions: синтаксис (`node --check` по каждому `src/*.js`), тесты,
  линт; деплой статики на GitHub Pages.
- `package.json`: скрипты `start`, `test`, `lint` — существующие не удалять.

## Правила

1. Не редактируй мои файлы: `map42.js`, `textures.js`, `props.js`, `world.js`,
   `monster.js`, `scares.js`, `jumpscare.js`, `index.html`, `style.css`,
   `README.md`, `docs/DESIGN.md`.
2. Не трогай `src/main.js` и `src/enemy.js` — это игровая логика. Если видишь
   там баг — запиши в `docs/PARALLEL-NOTES.md` (твой файл, дописывать в конец),
   я прочитаю перед своим коммитом.
3. Не меняй баланс: слух, зрение, скорость, батарею, панику, условия смерти и
   победы. Только звук, тесты, CI.
4. Маленькие коммиты, свой PR, ветка — своя.

## Готово, если

- `src/audio.js` переписан, контракт `GameAudio` цел, файлов-ассетов нет;
- звук различает помещения и поверхности, у каждого события `scares.js` свой
  стингер, общий выход в норме;
- `tools/validate-world.mjs` в репозитории и проходит;
- `node --test tests/map42.test.mjs` — 11/11, плюс твои новые проверки;
- CI зелёный, игра открывается с `python3 -m http.server` без ошибок в консоли;
- `docs/AUDIO.md` описывает карту звуков и уровни.

Начни с того, что прочитаешь `docs/PARALLEL.md` и `docs/DESIGN.md`, покажешь
план работы на 3–5 шагов и спросишь, что уточнить. Не начинай правки, пока не
подтвердят разделение файлов.
