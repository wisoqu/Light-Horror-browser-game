# Дежурная не ушла

Короткая 2D horror stealth-игра для браузера. Ты заперт в ночной школе, свет выключен, а дежурная все еще ходит по коридорам.

## Запуск

Открой `index.html` в браузере или запусти простой локальный сервер:

```powershell
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Управление

- `WASD` или стрелки: движение
- `Shift`: бежать, но это громко
- `Q` / `R`: повернуть фонарь
- `Space`: восстановить ближайший щиток
- `E`: спрятаться у шкафчика, если стоишь рядом
- `Enter`: начать заново после проигрыша

Цель: восстановить 4 щитка и не попасться.
